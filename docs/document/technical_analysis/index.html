TECHNICAL ANALYSIS

技术分析

从 K 线、时间周期和成交量开始， 系统学习趋势、均线、MACD、KDJ、RSI、BOLL、 支撑阻力、价格形态以及多周期分析。 本课程重点不是记住指标公式， 而是理解价格行为、指标计算逻辑以及不同分析工具之间的关系。

18 篇系统课程 基础 → 实践 K 线与技术指标 STOCK LAB
COURSE OVERVIEW

这套课程学什么？

技术分析主要研究市场价格、成交量以及由这些数据计算得到的各种指标。 它与基本面分析关注的问题不同： 技术分析更加关注 价格如何变化、趋势如何形成、市场当前处于什么状态 ，以及不同时间周期上的价格行为。

很多人学习技术分析时， 会直接开始背 MACD、KDJ、RSI 的参数和金叉死叉。 但如果没有理解 K 线、时间周期、趋势和成交量， 指标很容易变成孤立的信号。

因此，本课程按照： K 线 → 周期 → 趋势 → 成交量 → 指标 → 形态 → 多周期 → 实践 的顺序展开。

学习目标 学完这套课程后， 你应该能够读懂不同周期的 K 线图， 理解主要技术指标的计算逻辑和使用场景， 能够结合趋势、成交量和多个指标观察市场状态， 并知道技术分析存在的局限性。

STUDY METHOD

建议这样学习

技术分析不适合只看文字。 最有效的学习方式是： 学一个概念，就在真实 K 线上寻找它。

01

先看价格，再看指标

先观察 K 线、趋势和成交量， 再打开 MACD、RSI 等技术指标。

02

同时观察多个周期

不要只盯着一个周期。 可以分别观察 M5、M15、60m、日线和周线， 理解价格在不同时间尺度上的变化。

03

不要孤立使用指标

MACD、KDJ、RSI 等指标都只是价格数据的不同数学表达。 应该结合趋势、成交量和价格结构理解。

04

用历史数据验证

如果把技术分析转化为交易规则， 应该进一步使用历史数据进行测试， 而不是只观察少量案例。
